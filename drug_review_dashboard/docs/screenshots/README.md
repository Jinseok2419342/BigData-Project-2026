# 앱 사용 화면 캡처 (보고서 5장용)

`보고서.md` 5장의 "사용 화면 캡처 (페이지별)" 표가 이 폴더의 이미지 6장을 참조한다.
아래 파일명 **그대로** 저장하면 보고서에 바로 표시된다.

| # | 저장할 파일명 | 페이지 | 찍을 장면 |
|---|---|---|---|
| 1 | `eda.png` | EDA 대시보드 | 요약 지표(행 수·위험군 비율 등)와 분포 그래프가 같이 보이는 상단 화면 |
| 2 | `visualization.png` | 인사이트 시각화 | 대표 그래프 1개 + 해석 캡션이 같이 보이게 (약물별 위험군 비율 Top20 추천) |
| 3 | `model_service.png` | 모델 서비스 | 약물명·증상 텍스트를 입력하고 예측 버튼을 누른 직후 — **입력값과 위험도(%) 결과가 한 화면에 같이** |
| 4 | `data_browser.png` | 데이터 조회 | 키워드/약물 검색 결과 테이블이 보이게 |
| 5 | `chatbot.png` | AI 상담 챗봇 | 질문 1개와 근거 기반 답변이 보이게 |
| 6 | `multimodal.png` | 모델 서비스 내 이미지 인식 탭 | `L-methylfolate.png` 업로드 → 약물명 매칭 결과 (보너스, 여유 있을 때) |

## 찍는 방법

1. `streamlit run app.py` 실행
2. 각 페이지로 이동 → 결과가 뜬 상태에서 `Win + Shift + S` (영역 캡처)
   - **사이드바를 포함**해서 찍으면 멀티페이지 구성도 함께 증명됨
   - 모델 서비스 입력값은 **발표 데모에서 쓸 값과 동일하게** (보고서·발표 일치)
   - 6장 모두 같은 폭으로 찍으면 표에서 깔끔하게 정렬됨
3. 캡처를 그림판 등에 붙여넣어 이 폴더에 위 파일명으로 PNG 저장

> 6번(multimodal)을 생략하려면 `보고서.md` 5장 마지막 표의 오른쪽 칸을 지우면 된다.
