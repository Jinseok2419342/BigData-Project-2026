## 2. 풀고 싶은 문제
"환자들이 작성한 실제 약물 복용 리뷰 및 평점 데이터로 알려지지 않은 약물 부작용(ADE) 가능성을 조기에 탐지하고, 환자들이 약을 먹기 전이나 먹고 난 후에 참고할 수 있게 하고 싶다"  <br>

예측/분류 대상(target) - 환자가 겪은 이상 증상이 즉시 조치가 필요한 '심각한 부작용 위험군(1)' 인지, 일반적인 불편함이나 긍정적 반응인 '일반 리뷰(안전군)(0)' 인지 분류 (이진 분류)  <br>

## 3. 만들 서비스(완성모습)

[무엇을 입력 -> 무엇을 보여주나]
- [입력 1 - 텍스트]: 대상 약 이름 or 환자가 호소하는 부작용/복용 텍스트 원문, 혹은 둘 다를 자유롭게 직접 입력
- [입력 2 - 이미지]: 약통 이미지를 업로드 (멀티모달 인터페이스)  <br><br>

- [출력(보여주는 것)]: Streamlit 기반 종합 관제 대시보드
    - 실시간 추론 화면: 입력창에 약 이름과 부작용을 넣고 버튼을 누르면, 통계(IQR)가 해당 약의 평점 추이 중 이상치인지를 파악하고, 머신러닝(ML)이 위험도 점수(%)를 계산하여 '심각한 부작용 위험군'인지 안전군인지 초고속 분류 결과를 보여줌.

    - LLM 심층 진단 리포트: 환자가 약이나 증상에 대해 날것으로 쓴 문장(예: "심장이 터질 것 같다")을 LLM이 해당 약의 증상들을 참고해 가능성 제시(약통 이미지를 넣었을 때는 해당 약을 자동으로 인식해 약물 정보를 매칭해줌)

    - 종합 모니터링 및 챗봇 탭: 각각의 약물의 역대 평점 분포 차트, 가장 많이 보고된 부작용 키워드  등을 보여줌. (하단에는 해당 약물의 주의사항이나 부작용 히스토리를 질의응답 할 수 있는 AI 상담 챗봇 배치 고려)

<br>
[사용할 기술(아래 중 택1 이상): ML / 딥러닝 / LLM]

- ML: Random Forest / XGBoost (부작용 위험도 수치 예측 및 위험군 이진 분류)

- LLM: Ollama (gemma4 기반) or LLM API 키로 정성적 증상 의학 용어 표준화, 멀티모달 약통 인식 시연 및 부작용 전용 챗봇 구현

## 4. 예상 난관 1가지
