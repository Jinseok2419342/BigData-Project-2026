# 5분 발표자료: 약물 리뷰 기반 부작용 위험 탐지

## 1. 주제와 문제

환자 약물 리뷰와 평점 데이터를 이용해 심각한 부작용 위험군을 빠르게 탐지하는 Streamlit 서비스를 만들었다.

핵심 질문:

> 환자가 쓴 자유 텍스트 리뷰만 보고 "즉시 주의가 필요한 위험 신호"를 찾아낼 수 있을까?

## 2. 데이터

- UCI ML Drug Review dataset
- Kaggle: `jessicali9530/kuc-hackathon-winter-2018`
- 약 161,290행, 7열
- 주요 컬럼: 약물명, 질환, 리뷰, 평점, 날짜, usefulCount

## 3. Target 만들기

원본에는 심각한 ADE 라벨이 없어 약한 라벨링을 적용했다.

- 심각 증상 키워드 포함: 위험군
- 낮은 평점 + 증상 키워드 포함: 위험군
- 나머지: 일반 리뷰/안전군

## 4. EDA 핵심

- 낮은 평점 구간에서 위험군 후보가 많이 나타난다.
- 약물별 리뷰 수 편차가 커서 최소 리뷰 수 필터가 필요하다.
- 심각 증상 키워드와 리뷰 길이가 분류에 의미 있는 신호가 된다.
- IQR을 이용하면 같은 약물 안에서 유난히 낮은 평점 리뷰를 감지할 수 있다.

## 5. 모델

- RandomForestClassifier 사용
- 입력: 리뷰 텍스트 TF-IDF + 숫자형 특성
- 출력: 위험도 확률과 위험군/안전군 분류
- 서비스 페이지에서 Accuracy, Recall, F1, 혼동행렬, 특성 중요도를 확인할 수 있다.

## 6. 서비스 시연 흐름

1. EDA 페이지에서 데이터 분포 확인
2. 시각화 페이지에서 위험군 비율이 높은 약물과 키워드 확인
3. 모델 서비스 페이지에서 약물명, 증상 텍스트, 평점 입력
4. 위험도 점수, IQR 이상치 여부, 과거 유사 리뷰, AI 상담 리포트 확인

## 7. 한계와 개선

- 실제 ADE 전문 라벨이 아니라 약한 라벨을 사용했다.
- 약물 용량, 병력, 병용약 정보가 없다.
- 이미지 업로드는 현재 미리보기와 파일명 기반 후보 매칭까지만 구현했다.
- 향후 OCR/멀티모달 LLM, 실제 ADE 라벨 데이터, threshold 튜닝으로 개선할 수 있다.

## 8. 결론

이 프로젝트는 EDA, 시각화, 머신러닝 예측, Streamlit 서비스를 하나로 묶어 환자 리뷰 데이터가 실제 의사결정 보조 서비스로 확장될 수 있음을 보여준다.
