# 5분 발표자료: 약물 리뷰 기반 부작용 위험 탐지

> 슬라이드 6장 · 데모(슬라이드 4)에서 점수가 갈립니다. 그래프/화면 위주로.

## 1. 제목

UCI 약물 리뷰 데이터로 **심각한 부작용(ADE) 위험군을 탐지**하는 Streamlit 서비스 — 장진석 / 20241499.

> 핵심 질문: 환자가 쓴 자유 텍스트 리뷰만 보고 "즉시 주의가 필요한 위험 신호"를 찾을 수 있을까?

## 2. 문제정의 & 데이터

- UCI Drug Review Dataset (Drugs.com) — Kaggle 재배포 `jessicali9530/kuc-hackathon-winter-2018` 사용
- 라이선스: UCI **CC BY 4.0** / Kaggle 재배포본 **CC BY-NC-SA 4.0** → 엄격한 쪽 준수(비상업적·수업용)
- **215,063행 × 7열** (train 161k + test 54k), 컬럼: 약물명·질환·리뷰·평점·날짜·usefulCount
- target: 위험군(1) / 안전군(0) **이진 분류**

## 3. EDA·시각화 발견 (그래프 1~2장)

- 평점이 **J자형**(10점·1점 양극단), 위험군 평점 중앙값 2 vs 안전군 9 → 뚜렷이 분리
- 질환은 `Birth Control`(38k)이 최다, 약물 3,671종으로 편차 큼
- **데이터 품질**: `condition` 1,171행에 HTML 잔여물 → 전처리 필요
- 상관 히트맵에서 **누수 단서**(severe_keyword 0.64) 포착 → 슬라이드 5로 연결

## 4. 데모 (라이브) — 미리 정한 입력

1. 모델 서비스 페이지에서 약물명 = `Sertraline`
2. 증상 = "Severe chest pain and my heart was racing, I could not breathe."
3. 평점 = 2 → **위험도 약 78%, 위험군** + IQR 이상치 + 상담 리포트 출력
4. (옵션) 약통 이미지 업로드 → Ollama 멀티모달 약물명 인식

## 5. 모델·특성·성능 ⭐ — "정직한 숫자"

- 처음엔 Accuracy 99.6% / AUC 1.0 → 알고 보니 **데이터 누수**(라벨 정의 키워드를 그대로 학습)
- 라벨 정의 컬럼(severe/symptom 카운트, low_rating) **제외** 후 재평가:

| 모델 | F1 | AUC |
|---|:---:|:---:|
| RandomForest(배포) | **90.2%** | 0.983 |
| HistGradientBoosting | 97.4% | 0.988 |
| 단순규칙(rating≤3) | 61.9% | — |

→ ML이 단순 규칙을 크게 능가. 상위 특성도 rating·hospital·er·swelling 등 **의미 있는 토큰**.

## 6. 결론·한계

- 결과: 리뷰 텍스트로 위험군을 정직한 F1 0.90 수준 분류
- 한계: 약한 라벨이 텍스트 파생 → "키워드 일반화"이지 미지 ADE 발견은 아님 (완곡 표현은 놓칠 수 있음)
- 향후: Recall 우선 threshold 튜닝, 실제 ADE 라벨 결합, 멀티모달 강건화
