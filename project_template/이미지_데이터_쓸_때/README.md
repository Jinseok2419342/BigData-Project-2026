# 이미지 데이터를 쓸 때

표(CSV)가 아니라 **이미지 폴더**로 프로젝트를 한다면, **적재·EDA만** 이 변형본으로 바꾸면 됩니다.
모델/서비스는 템플릿 `pages/3_모델_서비스.py`의 **경로 B (사전학습 ViT pipeline)** 를 그대로 쓰세요. (11·12주 코드)

## 1) 폴더 구조 — 클래스 = 폴더 이름
```
data/images/
├── cat/   img001.jpg img002.jpg ...
└── dog/   img050.jpg img051.jpg ...
```
> 템플릿에 **샘플 이미지(cat/dog)** 가 이미 들어 있어 바로 실행됩니다. 확인 후 **본인 데이터로 교체**하세요.

## 2) 파일 2개만 덮어쓰기
| 원본 | 이걸로 덮어쓰기 |
|------|----------------|
| `src/data_loader.py` | `data_loader_image.py` |
| `pages/1_EDA.py` | `1_EDA_image.py` |

> `data_loader_image.py`에는 `load_image_meta()`와 호환용 `load_data()`가 둘 다 들어 있어,
> **`2_시각화.py`는 그대로** 이미지 크기·클래스 분포 그래프를 그립니다(덮어쓸 필요 없음).

## 3) 모델/서비스 (`pages/3_모델_서비스.py`)
- **경로 A(머신러닝)** 부분을 지우고 **경로 B(이미지 분류)** 주석을 해제하세요.
- `st.file_uploader`로 이미지를 받아 사전학습 ViT pipeline으로 분류 → 결과 표시.

## 4) 실행
```bash
streamlit run app.py
```

## 표 EDA와 다른 점
| | 표(CSV) | 이미지 |
|---|---------|--------|
| 적재 | `read_csv` | 폴더 스캔 → **메타데이터 DataFrame**(경로·라벨·크기) |
| 통계 | `describe()`, 결측 | **클래스별 장수**, 크기·컬러모드 분포 |
| 시각 | 히스토그램·산점도 | **샘플 이미지 그리드** + 크기 산점도 |

> 실제 이미지는 전부 메모리에 올리지 않고 **PIL로 1장씩** 엽니다 (강의실 8GB 보호).
